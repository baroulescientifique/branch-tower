# BranchTower

Open your application Git repository in Codex or Claude Code. Invoke `$branchtower` in Codex or `/branchtower:branchtower` in Claude Code and describe the change you want.

The planner prepares a specification and task list for your approval. After approval, workers appear under the current chat. Ask the chat to show the workers or send a direction to a named worker. A fresh verifier checks the combined commit.

For the exact approval, steering, and release steps, read the [workflow](skills/branchtower/SKILL.md).
